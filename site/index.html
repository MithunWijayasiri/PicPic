Features

Small app. Full toolbox.

Everything you need to view, tweak and present images. Nothing you don't.

Basic editing

Rotate, flip, crop, and convert file types instantly without opening a heavyweight image editor.

Slideshow

Sit back and let your folder play automatically, complete with a clean checkerboard backdrop for transparency.

Print & PDF

Print any photo cleanly or export straight to a standalone PDF in a couple of clicks.

Image details

Dimensions, size, color profile, and file type at a glance. No extra dialog hunting.

Formats
