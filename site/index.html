Features

Small app.
Full toolbox.

Everything you need to view, tweak and present images — nothing you don't.

Basic editing

Rotate, flip, crop and convert file types without opening a heavyweight editor.

Window modes

Picture-in-picture, frameless and always-on-top — keep an image visible while you work.

Slideshow

Sit back and let your folder play itself, with a checkerboard backdrop for transparent files.

Print & PDF

Print any image or export it straight to PDF in a couple of clicks.

Set as wallpaper

Found the one? Make any image your desktop background directly from the viewer.
