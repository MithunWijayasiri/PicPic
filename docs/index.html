Hover the preview — the HUD fades in, then gets out of the way.

Zen HUD

No toolbars or status bars. A floating dock and info chip appear when you move the mouse and fade when you don't.

Modern .NET

Rebuilt on modern .NET with crisp per-monitor DPI scaling and a native dark title bar.

Modern formats

WebP, AVIF and more, alongside the classics — without a heavyweight runtime.

Portable

A single self-contained executable, with an optional installer for file associations.

PicPic is based on Quick Picture Viewer by ModuleArt. github.com/MithunWijayasiri/PicPic
